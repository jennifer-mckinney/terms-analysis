## Federal

### COPPA — 15 U.S.C. §§6501-6506

- **Authoritative source URL (statute):** https://uscode.house.gov/view.xhtml?req=granuleid%3AUSC-prelim-title15-chapter91&edition=prelim (verify chapter/section on fetch)
- **Authoritative source URL (rule):** https://www.ecfr.gov/current/title-16/chapter-I/subchapter-C/part-312 (verified via WebSearch 2026-07-04 — ecfr.gov may 302-redirect to unblock; access via direct https)
- **License:** Public domain (17 U.S.C. §105 for statute; FTC rule text is US Gov work)
- **Version identifier:** Statute is 1998 baseline. Rule: FTC published final amendments in Federal Register on **2025-04-22**; amended Rule effective **2025-06-23**; general compliance deadline **2026-04-22**; §312.11(d)(1), (d)(4), (g) have separate compliance dates.
- **Structural hierarchy:** Statute → Section (§650x). Rule → Section (§312.x) → subsections (a)(b)(c)...
- **Chunking recommendation:** Per section, 512-1024 tokens, 128-token overlap per LIB-LEGAL. Definitions section (§312.2) has many terms — chunk per definition, not per section, to preserve semantic units.
- **Metadata schema per chunk:** see Cross-cutting decisions below.
- **Rendering behavior in revamp UI:** Citation format `COPPA §312.4(c)(1)` clickable → opens ecfr.gov subsection anchor.
- **Placeholder-to-real cutover checklist:**
  - [ ] Fetch 2025 amended Rule text from ecfr.gov (not FTC blog paraphrases)
  - [ ] Chunk per subsection with metadata
  - [ ] Diff against placeholder in `data/legal_corpus/us_coppa/`
  - [ ] Update `legal_kb.py` index build to include new chunks
  - [ ] Re-run embedding + numpy exhaustive search validation
  - [ ] Verify citation-resolver renders 2025 amendments correctly in v2 UI
- **Version-refresh policy:** Per-session refresh via version-check gate on ecfr.gov "amendment date" header; store hash in `_governance-manifest.json` extension for legal corpus.
- **Recent developments:** 2025-04-22 FTC final rule adds new definition (biometric identifier), expands parental consent requirements, tightens third-party disclosure rules. Material change from prior 2013 text.
- **Legal-review gates:** Counsel confirm (a) 2025 Rule text is authoritative version to embed (not FTC's summary blog), (b) FTC guidance documents excluded from corpus unless flagged as guidance not statute, (c) tribal/state COPPA-adjacent laws not conflated.

## Cross-cutting decisions

### Chunking strategy summary

- **Statutes:** Section-level chunks, 512-1024 tokens, 128-token overlap (per LIB-LEGAL).
- **Definitions sections:** Per-term chunks (they're semantic units, not narrative).
- **Long sections (>1024 tokens):** Sub-chunk by subsection with parent-section anchor preserved in metadata.
- **Rules (regulatory text):** Same as statutes, but tag `source_type: rule` and preserve rulemaking-history URL.

### Metadata schema per chunk (JSON snippet)

```json
{
  "chunk_id": "us_ca_ccpa_1798_140_a",
  "jurisdiction": "US-CA",
  "statute_code": "CCPA",
  "citation": "Cal. Civ. Code §1798.140(a)",
  "structural_path": ["Title 1.81.5", "§1798.140", "(a)"],
  "text": "...",
  "token_count": 812,
  "source_url": "https://leginfo.legislature.ca.gov/faces/codes_displayText.xhtml?...&title=1.81.5",
  "source_anchor": "1798.140",
  "source_type": "statute",
  "effective_date": "2026-01-01",
  "last_amended": "2026-01-01",
  "amendment_ref": "Stats. 2025 Ch. 67 §27 (AB 1170)",
  "license": "public_domain",
  "status": "active",
  "status_notes": null,
  "fetched_at": "YYYY-MM-DDTHH:MM:SSZ",
  "fetched_hash": "sha256:...",
  "version_floor": "2026-current"
}
```

Additional status enums: `active | vacated | superseded | forthcoming | revoked`. Use `status_notes` to reference the vacating court order or replacing statute.

### Attribution & version-refresh policy

- **Per-session refresh gate:** On agent startup, compare `fetched_hash` for each chunk against a re-fetch of the source URL's "amendment date" header (leginfo.legislature.ca.gov, ecfr.gov, uscode.house.gov all expose this). If mismatch → flag for re-ingestion, don't silently serve stale text.
- **Manifest extension:** Extend `.claude/_governance-manifest.json` with a `legal_corpus_manifest` block tracking `{jurisdiction, statute, fetched_hash, fetched_at, version_floor}`.
- **Attribution in UI:** Every citation surfaces `source_url` + `last_amended` + `status`. Vacated/superseded/revoked chunks render with a status badge.

### State-law-tracker source

- **Primary:** IAPP US State Privacy Legislation Tracker — https://iapp.org/resources/article/us-state-privacy-legislation-tracker (paywall-gated for detail; use IAPP news posts for effective-date updates as free surface).
- **Secondary:** NCSL comprehensive-privacy tracker — https://www.ncsl.org/technology-and-communication/state-laws-related-to-digital-privacy (verify current URL at fetch).
- **Tertiary (AI laws):** Orrick US State AI Law Tracker — https://ai-law-center.orrick.com/us-ai-law-tracker-see-all-states/
- **Policy:** Cross-check any new state at ingestion time against at least two of these three; disagreement = escalate to counsel.
